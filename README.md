# MultiClone — обновления

Публичный канал выпусков MultiClone. Исходного кода здесь нет.

- **Скачать последнюю версию:** раздел [Releases](../../releases).
- `channels/stable.json`, `channels/beta.json` — подписанные манифесты (Ed25519), по ним
  приложение проверяет обновления.
- `history/` — манифесты всех выпусков, [HISTORY.md](HISTORY.md) — список изменений.

Файлы в этом репозитории публикует автоматика сборки. Вручную их не правят: изменённый
манифест не пройдёт проверку подписи в приложении.
