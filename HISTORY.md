# История обновлений MultiClone

## 0.2.1 (stable, 2026-11-08)

- Выбор режима папки Android/data для каждой игры: общая / файлы входа свои, ресурсы общие / у каждого профиля вся своя.
- Режим «вся своя»: каждый профиль хранит полную копию данных игры (ресурсы скачиваются для каждого профиля отдельно, нужно больше места).


## 0.2.0 (stable, 2026-11-08)

Профили теперь переключают и файлы входа в Android/data.
- Watcher of Realms хранит вход не только во внутренних данных, но и в Android/data (PlayerPref.bin и соседние файлы). Теперь они переключаются вместе с профилем.
- Тяжёлые ресурсы игры (около 7 ГБ) остаются общими для всех профилей — ничего не докачивается.
- Защита от сбоя посреди переключения распространяется и на эти файлы.
- Поиск файлов входа больше не забивается загружаемыми ресурсами.


## 0.1.2 (stable, 2026-11-08)

- Диагностика сама сохраняется файлом в общую папку LDPlayer (Pictures/MultiClone): забрать на компьютере через кнопку «Общая папка».
- Результат поиска файлов входа сохраняется и не пропадает при выходе с экрана.


## 0.1.1 (stable, 2026-11-08)

Диагностика для поиска, где игра хранит вход в аккаунт.
- Новая кнопка «Начать / Закончить поиск файлов входа»: показывает все файлы, которые игра изменила за это время.
- В отчёте: подробный список папок и мелких файлов в Android/data игры и корень памяти.


## 0.1.0 (stable, 2026-11-08)

Первая тестовая версия.
- Профили аккаунтов для любой игры: данные подменяются через root, игра остаётся оригинальной.
- Ярлыки профилей на рабочем столе: нажал — открылся нужный аккаунт.
- Диагностика: где игра хранит данные и сколько они весят, отправка журнала.
- Встроенная проверка обновлений с проверкой подписи.
